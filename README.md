# Udemy Website Clone

A static and responsive **Udemy website clone** built using HTML and CSS. This project was created to practice front-end development, responsive layouts, Flexbox/Grid, and recreating a real-world website structure.

## 🚀 Live Demo

[View Live Website](#)

## 📌 Project Overview

This project replicates the look and structure of the **Udemy website** with a focus on creating a clean, responsive, and user-friendly interface.

The website includes the main sections found on an online learning platform, such as navigation, course listings, recommended topics, popular courses, and a footer.

## ✨ Features

* Responsive navigation bar
* Udemy-inspired logo and search bar
* Navigation/menu section
* Recommended courses section
* Course cards with:

  * Course image
  * Course title
  * Instructor name
  * Rating
  * Reviews
  * Price
* Recommended topics section
* Topic suggestion input box
* Popular courses section
* Responsive footer with useful links
* Responsive layout for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Semantic page structure
* **CSS3** – Styling and responsive layout
* **Flexbox** – Layout and alignment
* **CSS Grid** – Course and content layouts
* **Google Fonts** – Typography
